# Atributos de calidad

Durante una campaña comercial, muchos clientes podrían consultar productos y realizar compras al mismo tiempo. Por ello, el marketplace debe considerar los siguientes atributos:

| ID | Atributo | Escenario de calidad |
|---|---|---|
| AC01 | Rendimiento | Las consultas de productos y las operaciones del carrito deben responder con rapidez, incluso con muchos usuarios simultáneos. |
| AC02 | Disponibilidad | La plataforma debe mantenerse disponible durante las campañas para que los clientes puedan realizar sus compras. |
| AC03 | Escalabilidad | El sistema debe poder atender un aumento de usuarios y solicitudes sin afectar significativamente su funcionamiento. |
| AC04 | Seguridad | Las cuentas, los datos personales y las operaciones de compra deben protegerse frente a accesos no autorizados. |
| AC05 | Mantenibilidad | Los módulos deben estar organizados para permitir cambios y correcciones sin afectar innecesariamente otras funcionalidades. |
