# Actores del sistema

| Actor | ¿Qué necesita realizar? |
|---|---|
| Cliente | Buscar productos, consultar su información, agregarlos al carrito, realizar pedidos, pagar y consultar el estado de sus compras. |
| Seller (vendedor) | Registrar y actualizar productos, consultar sus productos y gestionar la información de sus ventas. |
| Administrador | Gestionar los vendedores y administrar la plataforma. |
| Pasarela de pago | Procesar los pagos y comunicar el resultado al marketplace. |
| Servicio de envío | Gestionar la información y el estado de las entregas. |
| Servicio de facturación | Generar los comprobantes de pago. |
| ERP | Proporcionar información de productos y stock. |

Los actores están fuera del marketplace e interactúan con él. La aplicación web y la API REST son partes del sistema, por lo que no se consideran actores.
