# Restricciones del sistema

Las restricciones son condiciones que deben respetarse al diseñar y desarrollar el marketplace.

| ID | Restricción | Descripción |
|---|---|---|
| RC01 | Aplicación web | Los usuarios deben acceder al marketplace mediante un navegador web. |
| RC02 | Control de versiones | El proyecto debe gestionarse con Git y publicarse en un repositorio compartido de GitHub. |
| RC03 | API REST | La aplicación web debe comunicarse con el backend mediante una API REST. |
| RC04 | Pasarela de pago | Los pagos deben procesarse mediante una pasarela externa. |
| RC05 | Servicio de envío | La información de entrega debe gestionarse mediante la integración con un servicio externo de envío. |
| RC06 | Documentación | Los documentos de análisis y arquitectura deben redactarse en Markdown; el diagrama inicial se elaborará en Mermaid o draw.io. |
